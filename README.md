## 記録のルール

- 所持巻は本人申告をもとに記録し、発売されても自動では所持済みにしない
- 発売日・発売状況は出版社の情報を優先し、確認日と出典を残す
- 発売予定日は変更される場合あり。予定日を過ぎただけでは発売済みと扱わない
- 「購入可能」は発売済み・未所持の意味。各店舗の在庫までは確認していない
- 対象は日本語の漫画単行本。小説・分冊版・グッズ等は混在させない
- 所持本の紙／電子、通常版／特装版は未指定。所持巻を別版の未購入扱いにして重複追加しない
